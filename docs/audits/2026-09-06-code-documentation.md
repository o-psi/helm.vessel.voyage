# Code and documentation audit — 2026-09-06 UTC

Tracking: [#133](https://github.com/o-psi/voyage/issues/133). Audited source:
`327fc272949f2e6ea6b778a10842cf5e45080ca3`.

Four auditors read all 61 tracked Markdown documents fully (7,137 lines), including
AGENTS.md and the runtime prompt, before starting source comparison. They also read
all eight local planning/issue-draft notes (150 lines), Cargo.toml and the example
Helm configuration. The complete paginated inventory of 83 open and closed issues
was reviewed, refreshed, and relevant discussions and linked work inspected before
recording findings. This report adds no implementation changes.

Every session is a voyage, including ordinary local chat. Helm is the program.
The audit does not count configuration drafts or dedicated remote-worker primitives
as delivery of the planned multi-Helm operator experience.

Implementation order should first resolve credential/output handling, PTY privacy
and responsiveness, and unintended remote cancellation. Repair session/input
preservation and observational gaps alongside focused regression tests. Then settle
the remaining voyage scope/context/handoff contracts and implement the complete
operator workflows through both Helm and Vessel, retaining local execution
authority. Installation and real behavioral/deployment evidence remain delivery
requirements, not reasons to declare the underlying features complete early.

and existing test assertion review. This is not an exhaustive review of every
source line or proof of every documented invariant. Native Windows ACL internals,
all enrollment publication/terminal-secret permutations, transport/backpressure
matrices, ownership/cleanup races, transfer crash boundaries and every redaction
edge remain incompletely verified. No full workspace baseline, live provider,
macOS/Windows execution, power-loss test, deployed service or cutover run was
performed. Documentation-only publication checks do not replace those feature
acceptance requirements. No runtime fix or release-readiness claim is made here.

synthetic reproduction scripts/results are retained under
`.local-git/evidence/code-doc-audit/` in this audit workspace. They are ignored
local evidence, not files supplied by this report. The GitHub issues preserve the
reproduction outlines and required regression coverage. Rejected suspicions include
pasted bidi reaching terminal output (the reproduction did not show it), a missing
whole-task timeout (deliberate), and inert general consent being an authorization
bypass (it is explicitly not a live dispatcher).
